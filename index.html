42 is peer-graded and has no teachers. Every project is built from a subject PDF, has to pass the Norm, and gets defended line by line in front of other students. These start at libc and end at concurrency, shells and the STL.

Minishell C

A bash-like Unix shell: a prompt, a tokenizer, $VAR expansion, pipes, < > >> redirections, heredocs, and the builtins echo cd pwd export unset env exit.

The hard part: matching bash's behavior on quoting, exit codes and signals (Ctrl-C, Ctrl-D, Ctrl-\) across child processes without leaking a single file descriptor.

  • fork / execve
  • pipes
  • signals
  • readline

Philosophers C

The Dining Philosophers problem with one POSIX thread per philosopher and a mutex per fork, plus a monitor thread that detects death to the millisecond.

The hard part: no deadlocks, no data races, and no starvation, at any philosopher count.

  • pthreads
  • mutexes
  • timing

CPP Module 09 C++98

Three STL exercises: a Bitcoin price lookup built on std::map, a Reverse Polish Notation calculator on std::stack, and PmergeMe, an implementation of Ford-Johnson merge-insertion sort.

The hard part: keeping Ford-Johnson's comparison count under the theoretical bound, using Jacobsthal insertion order. There's a full write-up in the repo.

  • STL
